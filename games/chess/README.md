# チェス (Chess)

8x8ボードで駒を動かして相手のキングを詰める戦略ボードゲーム。プレイヤー（白）vs CPU（黒）の対戦形式。

## 画面解像度

1280x720 (16:9) に最適化。横長レイアウト（ボード左、情報パネル右）。

## 操作方法

1. 自分の駒をクリックして選択
2. 緑色にハイライトされた合法手をクリックして移動
3. ポーンが相手側の最後の行に到達するとプロモーション選択モーダルが表示される

## ルール

- 標準的なチェスルールに準拠
- キャスリング（キングサイド・クイーンサイド）
- アンパッサン
- ポーンプロモーション（クイーン、ルーク、ビショップ、ナイトから選択）
- チェック・チェックメイト・ステイルメイト判定

## API

### `game.handleCellClick(row, col)`
指定されたマスをクリック。駒の選択および移動を処理する。

- `row`: 行 (0-7, 0が最上段=黒側)
- `col`: 列 (0-7, 0が左端=a列)
- 自分の駒をクリック → 駒を選択し合法手をハイライト
- 合法手のマスをクリック → 駒を移動
- ゲームオーバー時、CPUターン時、プロモーション待ち時（`promotionPending !== null`）は無視される
- ポーンが最終行に到達すると `promotionPending` がセットされ、`completePromotion(type)` の呼び出しが必要になる

### `game.getValidMoves(player)`
指定プレイヤーの全合法手を取得する。

- `player`: `1`(白) または `2`(黒)
- 戻り値: `Array<{ fromRow, fromCol, toRow, toCol }>` — チェック回避を考慮した合法手の配列

### `game.getGameState()`
現在のゲーム状態をオブジェクトで返す。

- 戻り値:
  ```json
  {
    "board": [{ "row": 0, "col": 0, "color": "black", "type": "R", "notation": "a8" }, ...],
    "currentPlayer": "white" | "black",
    "gameOver": false,
    "inCheck": false,
    "lastMove": { "from": { "row": 6, "col": 4 }, "to": { "row": 4, "col": 4 } },
    "capturedWhite": ["P", "N"],
    "capturedBlack": ["P"]
  }
  ```

### `game.completePromotion(type)`
プロモーション待ち状態のポーンを指定した駒に昇格させる。

- `type`: 昇格先の駒タイプ。`"Q"`(クイーン), `"R"`(ルーク), `"B"`(ビショップ), `"N"`(ナイト)
- `game.promotionPending` が `null` でないときに呼び出す
- 呼び出すとプロモーションモーダルが閉じ、CPUのターンに移行する

### `game.promotionPending`
プロモーション待ち状態を示すプロパティ。

- ポーンが最終行に到達すると `{ row, col, color }` がセットされる
- プロモーション完了後は `null` に戻る
- この値が `null` でない間、`handleCellClick` は無視される

### `game.gameOver`
ゲーム終了フラグ。チェックメイトまたはステイルメイトで `true` になる。

### `game.init()`
ゲームを初期状態にリセットする。

### `game.undo()`
プレイヤーの手とCPUの手の2手分を巻き戻す（待った機能）。白のターンかつゲーム中のみ有効。

## 駒タイプ

| 記号 | 駒名 |
|------|------|
| K | キング |
| Q | クイーン |
| R | ルーク |
| B | ビショップ |
| N | ナイト |
| P | ポーン |

## ボード座標

- 行(row): 0(8段目/黒側) 〜 7(1段目/白側)
- 列(col): 0(a列) 〜 7(h列)
- 代数式表記: `a8`(row=0,col=0), `e1`(row=7,col=4)

## AI

Minimax探索（深さ3）+ Alpha-Beta枝刈り。評価関数は駒の素材価値＋位置ボーナステーブルを使用。

CPUの手は500ms後に自動実行される。`currentPlayer` が `2`(黒) の間はCPUが思考中。操作は白のターン（`currentPlayer === 1`）に戻るまで待つこと。
