# マインスイーパー

クラシックなマインスイーパーゲーム。地雷を避けてすべての安全なセルを開こう！

## 難易度

| 難易度 | サイズ | 地雷数 |
|--------|--------|--------|
| 初級 | 9×9 | 10 |
| 中級 | 16×16 | 40 |
| 上級 | 16×30 | 99 |

## 操作方法

- **左クリック**: セルを開く
- **右クリック**: 旗を立てる / 外す
- **開いた数字セルをクリック**: 周囲の旗の数が一致していれば、残りの未開封セルを一括で開く（コード開き）

## API

### `game.handleCellClick(row, col)`
指定セルを左クリックと同様に開く。

### `game.toggleFlag(row, col)`
指定セルに旗を立てる / 外す。

### `game.getGameState()`
現在のゲーム状態を取得する。

```javascript
{
    difficulty: "easy",
    rows: 9,
    cols: 9,
    totalMines: 10,
    opened: 15,
    flagged: 3,
    gameOver: false,
    gameStarted: true,
    timer: 42
}
```

### `game.init()`
ゲームをリセットする。

### ボード状態の読み取り

- `game.board[row][col]`: セルの値（-1: 地雷, 0: 空, 1-8: 周囲の地雷数）※ゲーム開始前は全て0
- `game.revealed[row][col]`: 開封済みかどうか（true/false）
- `game.flagged[row][col]`: 旗が立っているか（true/false）

## ルール

1. 最初のクリックは安全（地雷が配置されない）
2. セルを開くと周囲8マスの地雷の数が表示される
3. 数字が0のセルを開くと周囲の0セルが連鎖で開く
4. 地雷を踏むとゲームオーバー
5. 地雷以外のすべてのセルを開くとクリア
